# RANDOM_TYPE

**キーボードのキーがランダムに入れ替わる、ブラウザで遊ぶタイピングゲーム。**

1文打ち終わるたびにキーの配置がシャッフルされます。指が覚えている場所はもう信用できません。画面のキーボードを見て、入れ替わったキーを探しながら日本語の短文をローマ字で打ちましょう。

▶ **遊ぶ：https://mu4096.github.io/random-type/**

インストール不要。PC のブラウザと物理キーボードで遊べます（スマホ・タブレットは非対応）。

## 遊び方

1. タイトル画面で難易度を選ぶ（← → キーかクリック）
2. **日本語入力モードをオフ（半角英数）にして** Space か Enter キーを押すと、3・2・1 のカウントダウンで開始
3. 画面のキーボードで今の配置を確かめながら、表示された文章をローマ字で打つ
4. 制限時間は **90秒**。時間内に正しく打てた打鍵数を競うスコアアタック

| キー | 操作 |
|---|---|
| Space / Enter | 開始（結果画面では Space でもう一度、Enter でランキングと登録） |
| ← → | 難易度の切り替え |
| R | ランキングを見る（タイトル画面） |
| Backspace | ランキングに登録しない（結果から入ったランキング画面） |
| Esc | タイトルに戻る（プレイ中は中断） |

## 難易度

| 難易度 | 入れ替え方 |
|---|---|
| 🔥 簡単初心者モード | 毎回3キーずつ入れ替え。まだ動いていないキーだけが対象で、9回で全部入れ替わったら固定 |
| 🔥🔥 ちょっぴり難しめモード | 毎回5キーずつ入れ替え。変化は蓄積し、ずっと入れ替わり続ける |
| 🔥🔥🔥 激ムズカオスモード | 毎回すべてのキーを入れ替え |

入れ替わるのはアルファベット26キーと伸ばし棒（ー）の27キーだけです。数字・記号・Space・Shift などは動きません。入れ替えのたびに、対象のキーはすべて前と違う場所に移ります。

## 特徴

- **柔軟なローマ字判定**：し＝si / shi / ci、ん＝n / nn / xn、っ＝子音の重ね / xtu / ltu、拗音の分解入力（し＋ゃ）などに対応
- **「QWERTY の癖」ミス**：入れ替わっているのに、元の QWERTY 配列の位置を打ってしまうと、通常のミスとは別の演出で教えてくれます
- **ヒント**：3秒入力がないと、次に打つべきキーが点滅
- **盛り上げ演出**：コンボ、15コンボからのフィーバー、紙吹雪、入れ替わったキーを見つけたときの「みっけ！」など。演出はスコアに影響しません
- **効果音**：素材ファイルを使わず、Web Audio でその場で合成（画面の隅でミュート可）
- **放置したときの宣伝動画**：タイトル画面で30秒操作しないと宣伝動画が流れ、何かキーを押すと戻ります（画面の隅の 📺 ボタンでオン・オフ）
- **結果とランキング**：打鍵数・kpm・ミス数・最大コンボと、GOD〜D のランク評価。難易度別に上位10件をブラウザ内（localStorage）に保存するローカルランキング

問題文は、日常・食べ物・動物・季節の行事・ことわざ・早口言葉などのオリジナル短文100文です。

## ローカルで動かす

必要なもの：[Node.js](https://nodejs.org/) LTS（v24 系）

```bash
git clone https://github.com/Mu4096/random-type.git
cd random-type
npm install
npm run dev
```

http://localhost:5173 を開くと遊べます。

> Windows の PowerShell でスクリプトの実行が無効になっている場合は、`npm` の代わりに `npm.cmd` を使ってください（例：`npm.cmd run dev`）。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバーを起動（http://localhost:5173） |
| `npm test` | Vitest でテストを1回実行 |
| `npm run test:watch` | テストをウォッチモードで実行 |
| `npm run build` | 型チェック（`tsc`）と `dist/` へのビルド |
| `npm run preview` | ビルド結果を確認（http://localhost:4173/random-type/） |

## 技術構成

- [Vite](https://vite.dev/) + TypeScript（フレームワーク・ランタイム依存なし）
- [Vitest](https://vitest.dev/) によるテスト
- GitHub Actions + GitHub Pages で公開。`main` に push するとテスト・ビルドして自動でデプロイ（テストが失敗したら公開しない）

ゲームロジック（キーの入れ替え・ローマ字判定・スコア・ランキング）は DOM に依存させず、Vitest でテストしています。
