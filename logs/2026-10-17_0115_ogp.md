## 目的
URL を Discord などで共有したとき、サイトの説明（と画像）が表示されるようにする（OGP）。

## 経過

- 01:16 表示する説明文と画像の有無をユーザーに確認 → 説明文はルール説明そのまま、画像は 1200×630 の大きな画像カード
- tools/ogp.html（タイトル画面と同じ配色・フォント）を作り、Edge のヘッドレスモードで public/ogp.png に書き出した
  - Git Bash から msedge.exe を呼ぶと書き出されなかった（終了コード2）。PowerShell から --user-data-dir を付けると書き出せた
- 修正依頼：RANDOM_TYPE の文字をタイトル画面と同じように傾ける → 同じ式（(--i - 5) × 1.2°）で傾けて書き出し直した
- index.html に description・og:*・twitter:card・theme-color を追加。npm run build で dist/ogp.png がコピーされ、og:image が公開 URL を指すことを確認

## 判断
- [確認済み] 説明文は「1文打つたびにキーが入れ替わる！制限時間90秒で何打鍵いける？」
- [確認済み] 画像は 1200×630 の大きな画像カード
- [AI判断] 画像の中身：タイトルと同じカラフルなキー風の「RANDOM_TYPE」、白いカードのルール説明（「キーが入れ替わる！」ピンク帯・「90秒」青）、一部が入れ替わったキーの列（T と R、O と U が色付き）。水玉の背景
- [確認済み] 「RANDOM_TYPE」の文字はタイトル画面と同じく1文字ずつ傾ける（-6°〜+6°、1.2°刻み）。ほかは傾けない
