# ランキング画面に「登録しない」を追加
- 状態: 完了
- 開始: 2026-10-16 23:13

## 目的
結果から入ったランキング画面で、ランクインしていても登録を断れる選択肢を明示的に用意する。

## 経過
- 23:13 動きとキーをユーザーに確認した
- 23:13 「登録する」の隣に「登録しない」ボタンを置き、Backspace とクリックで通常のランキング画面に切り替えるようにした
- 23:14 ブラウザで確認：ランクイン時に2つのボタンが並ぶ、Backspace・クリックで「あなた」の行が消えて通常の操作案内になる（保存されない）、入力欄を開くと2つとも隠れる。テスト・ビルドも通過

## 判断
- [確認済み] 「登録しない」を選ぶと「あなた」の行を消して通常のランキング画面になる（←→で難易度切り替え、Space・Enterでプレイ、Escでタイトル）
- [確認済み] キーは Backspace。クリックできるボタンを「登録する」の隣に置く
- [AI判断] 「登録しない」ボタンは白（登録するは青）で、ニックネーム入力中は2つとも隠す
- [AI判断] Backspace は自動リピートを無視し、preventDefault する。入力中の Backspace は文字の削除のまま
- [AI判断] README の操作キー表に Backspace を追加
