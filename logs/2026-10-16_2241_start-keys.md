# 開始キーを Space / Enter に変え、開始時の IME 判定をやめる
- 状態: 完了
- 開始: 2026-10-16 22:41

## 目的
- 開始キーを F から Space と Enter の2つに変える
- 開始キーを押したときの IME 判定（ON なら開始せず警告）をなくし、タイトル画面に「日本語入力モードをオフにしてください」を常に表示する
- プレイ中の IME 判定（警告を出して打鍵を無視）はそのまま残す

## 判断
- [確認済み] 結果画面の「もう一度」、ランキング画面の「この難易度をプレイ」も Space / Enter に変える。F は使わなくなる
- [AI判断] テンキーの Enter（NumpadEnter）も開始キーに含める
- [AI判断] 押しっぱなしの自動リピートでは開始しない（ニックネーム入力の Enter を押したままだと、登録後のランキング画面ですぐ始まってしまうため）
- [AI判断] 開始キーでは preventDefault する（Space のページスクロールや、フォーカスの残ったボタンが Enter で押されるのを防ぐ）
- [AI判断] 案内は警告の赤ではなく黄色の札（⌨️ 付き）にし、操作案内のすぐ下に常に出す。文言はご指定どおり
- [AI判断] 結果・ランキング画面の開始キーにも IME 判定は入れない（Space・Enter は IME ON でも普通に届くため）
- [AI判断] README の遊び方・操作キー表も合わせて直した
